Can a drifting generative model keep its direct, one-step generation and also benefit from more inference steps? DFM learns transport between intermediate distributions, making both choices available to the same model.

The missing flexibility→Learn marginal transport→Scale inference steps

01 / The problem

Direct generation, with room to refine.

Flow-based and drifting models offer different ways to turn noise into data. The paper asks how to connect their inference behavior.

Flow Matching

Follow a velocity field.

Learn local dynamics along a noise-to-data path. Numerical integration offers a natural way to spend more computation at inference.

Drifting models

Learn a direct generator.

Use distribution-level drift during training to shape generated samples. A direct endpoint map supports one-step generation, but does not naturally specify intermediate inference steps.

Drift Flow Matching

Learn across time intervals.

Apply drift supervision between intermediate marginals. The learned transport can span the whole path in one call or compose shorter intervals.

02 / The mechanism

Match distributions along the path.

The probability path comes from Flow Matching. The learning signal is a distribution-level drift correction.

  1. Choose a time pair

    Sample noise x0, data x1, and a shared time pair t < r. Interpolate each endpoint pair at both times to sample pt and pr.

  2. Predict an interval transport

    Push samples from pt through the two-time model. Their predicted distribution is qt,r.

  3. Correct the predicted distribution

    Attract predictions toward pr and subtract self-attraction within qt,r. Fit the resulting stop-gradient targets.

xs = (1 − s)x0 + sx1,   s ∈ {t, r}

Learned transport

x̂r = xt + (r − t) uθ(xt, t, r)

Distribution-level training target

sg[x̂r + Vq,pᵣ(x̂r)]

DFM learns transport between marginal distributions using a drift objective. Endpoint pairs construct the path samples; the loss matches their distributions within each time-pair group.

Keep each marginal problem together.

Each time pair defines its own marginal transport problem. Compute drift within that group, using the grouped Sinkhorn field in Algorithm 2 of the paper.

At inference

Choose the grid. Reuse the model.

A single interval from 0 to 1 gives direct generation. A finer time grid composes the same learned transport across intermediate states. Each call evaluates the learned mean velocity uθ once.

Connection to Flow Matching

The constructed marginal path admits explicit Wasserstein bounds. Under the paper’s first-order consistency and regularity assumptions, the learned mean velocity approaches the local Flow Matching velocity as the interval shrinks.
